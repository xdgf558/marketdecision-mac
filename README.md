# MarketDecision Mac

macOS 美股与卖方期权工作台，目前处于 **Phase 0 基础工程审查**。当前应用只展示明确标注的合成数据，提供刷新、外观设置及 Mock 连接测试，没有真实行情、投资分析或交易能力。

工程与复跑说明见 [MarketDecision/README.md](MarketDecision/README.md)。Phase 0 尚未完成退出验收，UI 仍可迭代。
