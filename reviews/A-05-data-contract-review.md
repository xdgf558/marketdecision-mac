# A-05 数据契约审查摘要

状态：负责人要求创建本 PR 供其审查；等待审查摘要并决定是否合并。
本次交付是数据契约候选方案，不是数据库 schema、Swift 类型或应用实现。
完整契约目录、字段清单、案例、原规格、任务及项目记忆仅保留本地。

## 需要审查的契约方向

| 领域 | 本地发现与候选处置摘要 |
|---|---|
| 数值与结果 | 值、单位、币种、数值策略、模型/参数版本和输入引用一起保存；零值与缺值分开。账务 Decimal、理论量和测试容差各自有语义，不能把容差当舍入规则。 |
| 时间与修订 | 区分数据描述日期、源事件、请求接收、计算及每个 vintage 的现实可得时点。修订值不能沿用初次发布时点进入历史计算；AS_OF 不得回退为当前最新值。 |
| 数据层级 | 原层级同时混合来源、时效、加工和质量，无法可靠做单一强弱排序。候选拆成来源、时效、质量原因和用途资格四轴；衍生值继续携带全部实际输入限制。 |
| Provider 边界 | 请求显式区分 LATEST/AS_OF、用途、覆盖和部分响应；能力与当次授权分开。无 vintage 能力不能冒充历史点时查询成功，错误、空结果和部分覆盖分别表达。 |
| 证券与财报 | 证券使用稳定身份、历史代码有效期及股份类别；原始响应、申报、事实和映射修订分别版本化。当前 ticker、股数或修订事实不得回填历史。 |
| 股票与账本 EOD | 点报价、日线、复权及总回报口径分开；账本估值保存逐持仓价格来源、现金、负债、覆盖和缺口。当前期权链不得回填过去估值，Last+STALE 不得成为历史模拟成交。 |
| 期权与定价 | 完整期权链引用同请求周期的标的报价并记录逐项时差；Provider IV/Greeks 只作对照。本地定价绑定 S/K/T/r/q、模型及求解器配置，失败不得静默改用供应商值。 |
| 合约与公司行动 | 报价乘数、交割篮子、行权对价、最后交易、定价到期、实际行权及结算时点分开。复杂调整证据不足时阻断相关记账或定价，不能强套标准 100 股公式。 |
| 导入与成本批次 | 导入预览绑定文件、映射和目标账本版本，重复提交保持幂等；逐 lot 保存分配数量、费用和调整来源。转仓市值与继承成本分开，roll 和部分指派不重复计入权利金。 |
| 收益与策略回合 | 各收益指标按自己的必要输入判断可用性；中间 EOD 缺口对连续 TWR/回撤和 XIRR 的影响分开。目的成功、净盈利、未结束状态和样本分母分别保存。 |
| 概率与历史研究 | 校准及 Bootstrap 资格独立于可空的历史频率，保留样本、剔除原因和路线限制。匹配条件除哈希外还保存有序成员，随机结果绑定算法、数据、参数和种子。 |
| 市场、风险与决策 | 市场状态保存逐分项 vintage、窗口、缺失及确认链；扫描与风险冻结组合、资金、规则和情景版本。正式研究与决策从首次保存起追加版本，不等到复盘阶段再冻结。 |
| 复现与缓存 | 快照保存完整传递依赖、实际内容、参数、日历/映射及兼容模型实现；只有 input ID、哈希或版本名不足以保证重算。缓存清理在实际删除时重新校验引用，日摘要不能替代已引用明细。 |
| 备份与恢复 | 普通备份先生成一致性清单；恢复在隔离区预检、迁移并生成覆盖/合并计划。相同身份异内容保留两份及各自引用，完整校验后原子应用，失败保持原库；API Key 不进入普通备份。 |
| 提醒 | 规则、实际检查、系统调度分别保存；应用离线期间不能伪造检查连续性，系统未确认的通知不能标为已调度。事件改期或恢复后重建当前计划，不重放历史通知。 |

## 待确认与既有边界

- 上述方案按本地 CT-01 至 CT-12 分批审查，全部 DC 记录仍为 PENDING_REVIEW。公开摘要审查或合并不能批量批准字段、枚举、迁移或接口方案。
- 精度、舍入、费用、TWR/XIRR 输入、样本分母、评分权重、求解器和模型参数仍按 A-04 单独决定；结构完整不会自动给未填字段赋值。
- TTL、最大报价时差、用途资格、历史发布时间证据、恢复资源限制和冲突标识等仍待审或待 A-06 验证，不为完成契约而猜默认值。
- DATA-000 仍未选 A/B/C、不采购；未选路线不阻塞 Phase 1–4 或 Phase 5 独立工作，Phase 5 退出仍须结论。B 无校准且不默认完整回测页；C 不开放 Bootstrap，A/B 也不能因数据可用自动开放未定义能力。
- 账本 EOD 与历史回测数据继续分开。A-06 至少比较三家候选的数据覆盖、点时能力、许可与成本；延期不等于通过，扫描器不承诺上线日期。
- 原范围、阶段图、40 组计算候选和 47 项验收映射不因本稿改写。美式 CRR/离散股息、PDF/加密备份、AI 及其他后续能力不扩入本次。
- 本 PR 不启动 A-06、A-07、应用开发、UI 工作、数据采购或供应商接入。

## 验证与批准边界

本地结构检查覆盖 28 个固定契约组、原 13 节核心模型声明、40 组计算交接、任务/节点/测试引用、依赖无环及渲染一致性。
24 个合成案例仅为后续验收设计，运行时执行数量为 0；没有应用测试、数据库迁移、真实备份恢复、Provider 实测或 CI。
完整检查脚本和案例不公开，本摘要不能独立复跑，也不能证明字段语义完整、数据可行或金融模型获批。

具体契约批准须依据本地完整目录和审查队列，逐项记录接受的字段、语义、版本、迁移及未决项。
本次 PR 只审摘要准确性、公开边界及是否合并；等待负责人审查，不自动合并。
