# A-01 首版范围审查（精简公开稿）

状态：待审查。以下内容为建议，未批准、未合并，尚未进入应用开发。

本次解决首发功能、条件功能与延期功能的边界，使研发阶段和发布验收保持一致。仅包含本次范围审查摘要。

**批准边界：本公开稿不能单独批准 R-01 至 R-05，尤其不能据此批准 R-05 或锁定验收表。** 最终决定须由项目负责人同时审查本地 `A-01_SCOPE_REVIEW.md` 与 `A-01_ACCEPTANCE_MAP.md`；后者的 47 项逐条验收映射不在本 PR 中。批准本 PR 仅表示接受公开摘要的表述，不等于批准未公开的验收表。本 PR 的合并也须另经明确授权。

## 建议首发范围

| 领域 | 首发交付边界 |
|---|---|
| 公司研究 | 一般非金融企业财报导入、标准化、基本面与估值分析；结果可核对来源 |
| 自选与筛选 | 自选股和已缓存标的的本地筛选，不承诺全市场覆盖 |
| 行情与期权 | 股票和期权行情须标明数据层级、更新时间与质量，不得把延迟或陈旧当作实时；现金担保卖出 Put、备兑 Call、Put 信用价差、Call 信用价差；损益、资金占用、Greeks 和风险分析 |
| 账本与收益 | USD 本地组合、CSV/手工录入、成本批次、公司行动（Corporate Actions）处理、指派/行权、持仓、收益和归因 |
| 市场状态 | 市场热度、压力、情绪及可解释分项，保存历史市场状态快照；数据不足时明确不可用 |
| 扫描与决策 | 策略筛选、资金及集中度约束、硬性阻断、可解释排序、决策卡片 |
| 风险与复盘 | 组合风险、压力情景、不可覆盖的决策记录、实际成交关联和复盘 |
| 提醒 | 日期提醒及应用运行时的价格/风险检查，明确覆盖范围和实际调度状态；待触发容量有限，按最近触发时间滚动调度，超限项标明未调度 |
| 本地数据管理 | 报告与交易导出、备份、恢复、删除；恢复前展示内容清单，支持覆盖/合并，合并冲突保留两份供用户处理；不把密钥写入普通备份 |
| 发布基础 | 数据溯源与模型版本、离线缓存、安全、性能、可访问性、测试及签名公证 |

四种期权策略的概率、期望值和尾部损失必须说明测度与假设，不能把模型结果表述为真实胜率。数据缺失不补零，报价或资金条件不满足时不能照常排名。

## 历史回测与概率校准：条件交付

供应商验证仍在基础阶段启动，在扫描器阶段结束前明确数据方案。是否采购、选择哪家供应商以及采用哪个分支，均不由本次 PR 决定；数据覆盖与许可门槛不放宽。

| 路线 | 范围 | 必须满足的验收规则 |
|---|---|---|
| A 完整交付 | 数据覆盖和许可满足要求，并明确纳入本次发布后，交付完整历史回测与校准 | 无未来数据、时间分割、费用与成交假设、结果复现；样本和市场状态覆盖不足时隐藏校准输出 |
| B 降级交付 | 经明确批准，只提供样本内历史频率统计 | 标注窗口、样本量、置信区间及覆盖缺口；不提供校准概率、Brier Score 或可靠性图；保留防泄漏和复现验证 |
| C 延后交付 | 经明确批准，首发不提供历史期权回测和历史相似频率 | 期权决策只展示风险中性模型概率，不声称真实胜率；回测专有验收标为延期，不能标为通过 |

未明确选择 A/B/C 时，不得自动降级，且不阻塞 Phase 1–4 的独立开发；Phase 5 退出前仍必须有 DATA-000 结论，Phase 6 在结论明确前保持阻塞。B 路线是否包含交互式回测界面仍需另行明确，不在本次承诺。

C 路线不开放 Bootstrap 真实世界概率。Phase 6 延期时，扫描器应显示历史频率未启用的真实原因，不承诺上线日期。

C 路线不取消用户已导入实际成交的账本收益与策略统计；这些统计仍须满足样本展示限制，不能冒充历史独立验证或校准结果。模型期望值、尾部风险和确定性压力情景须各自明确口径，不能因回测延期而省略核心风险能力。

## 本地 AI 与阶段安排

建议本地 AI 延至后续版本。首发不集成模型、不提供 AI 摘要或检索入口，核心功能不依赖 AI；后续启用时再完整验收来源引用、用户确认、隐私和失败回退。

已批准延期的回测和 AI 不阻塞核心风险复盘或发布阶段。风险阶段仍须具备账本、行情、本地期权计算、市场快照和决策记录；发布阶段仍须通过所有已纳入首发功能的验收。历史回测尾部输入只在已实现且验证通过时使用。

不可覆盖快照、基本资金与集中度检查、导出和备份应随依赖它们的业务交付，不留到发布时临时补齐。具体任务依赖与调度不在本次 PR 中确定。

## 验收变化

- 财报、账本（含公司行动）、期权、风险、数据溯源、安全和发行门槛保留。本地公司行动固定案例验收仍必需，不能因摘要省略而豁免。
- 回测特有测试按明确选定的 A/B/C 路线执行；延期不是测试通过。已交付的历史财报和市场状态计算仍须遵守发布时点规则。
- 模型概率标注测度与假设；只有实际存在的历史统计才展示样本和置信区间，无数据时不得伪造 0% 或区间。
- AI 延期时仍验证核心无 AI 依赖；AI 专有测试随功能延期。
- 所有实际交付的计算都有相应固定案例或属性测试，不能以回测延期为由删除核心计算测试。

## 排除项

首发不做自动下单、裸卖、高频交易、社交跟单、云账户或资金托管、券商密码保存、税务申报、无条件 AI 买卖指令、未经许可的数据分发。复杂期权策略、专用行业模板、反向 DCF、模拟交易、完整研究报告、PDF 研究报告、加密备份、券商同步、移动端及商业化后续独立评估。普通本地备份仍在首发范围。
