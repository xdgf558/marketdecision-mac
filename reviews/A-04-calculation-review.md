## 本次审查内容

| 领域 | 本地发现与候选处置摘要 |
|---|---|
| 财务与估值 | 区分期间累计值、TTM、时点余额及每股口径；负基数、平均资本、租赁与债务聚合需明确规则。收益率反解价格须反向排序，多股权类别和企业价值桥接需独立定义。 |
| 费用与账本 | 净权利金和净损益中的同一费用只计一次；指派先算总成本再换算每股，区分部分指派与展期。公司行动须保留交割篮子，报价乘数不等于交割股数；转仓成本与外部流市值分开，桥接带入/带出的历史浮盈。 |
| 回合统计 | Expectancy 使用实际亏损频率或平均净损益，不能把零收益回合算作亏损；目的成功、净盈利及未结束状态分开。有效样本分母与最低样本门槛的适用范围仍需明确。 |
| 收益与利率 | 日终估值只能支持明确约定的日收益链接；XIRR 需多根、无解及求解容差策略。利率观察频率与年化单位分开，日收益/连续定价利率的转换模型待定。 |
| 期权损益与定价 | 每股/总额、保守买卖成交、费用分配、抵押资金及覆盖式卖购的收益基准分别定义。BSM、Greeks 单位、本地 IV 求解域与停止条件需固定；不得静默使用供应商 IV 作为求解失败替代。 |
| 尾部风险 | 同时保留带符号尾均值和非负损失；全盈利尾部不能取绝对值后称为损失，离散样本按精确尾部概率质量加权。 |
| 时间与事件 | 区分 DTE 与连续期限，半日市使用适用日历终点；盘前/盘后财报使用披露前后的窗口，禁止用事后期权链形成事前预期。提前指派启发式的阈值和误差边界仍待定。 |
| IV 与压力 | IV30 期限插值使用总方差并处理恰好目标期限；IV 小数与 VIX 点数先统一单位，区分百分点冲击与比例冲击；推进时间同步缩短期限，相关情景须有有效联合矩阵。 |
| 评分、市场与风险 | 基本面评分、市场子配方、流动性分档、扫描排名及组合风险仍有参数缺口；Beta 与 Delta 等不同风险量不混用。市场历史快照、数据版本及发布时点保留，禁止前视。 |
| 提醒与复现 | 阈值比较、去重、检查连续性及缺口状态需明确；提醒容量与恢复引用完整性仍需后续实现验证，所有正式计算保留输入、模型版本与状态。 |

以上仅说明发现及修订方向，不提供可直接实现的完整公式或默认参数。
评分权重、阈值、替代口径、样本资格、求解器与校准设置等未填写项继续待定。
不得以笼统确认、摘要批准或 PR 合并把未填字段视为已赋值，或把候选模型批量标为可用。

## 与已确认范围和顺序的关系

- 中间日估值缺失阻断连续 TWR、波动和回撤；完整现金流及有效端点仍可能足够求 XIRR。这是对指标输入条件的待确认澄清，不自动改写已批准的阶段图，也不降低 Phase 2 整体验收。
- 账本 EOD 与历史回测数据继续分开；行情标识数据层级、时间与陈旧状态，延迟或陈旧不得当作实时，Mid/Last 加陈旧标记不得成为历史成交数据。
- DATA-000 仍未选 A/B/C、不采购；未选路线不阻塞 Phase 1–4 或 Phase 5 独立工作，Phase 5 退出仍须有结论。可行性验证仍需至少三家候选，延期不等于通过。
- B 不包含校准，也不默认提供完整回测页；C 不开放 Bootstrap 真实世界概率，A/B 数据可用亦不自动启用未定义的 Bootstrap。
- Phase 7 核心继续独立于 Phase 6；历史研究延期时扫描器不得承诺上线日期。无条件 AI 买卖指令、美式 CRR/离散股息等原后续边界不因本稿扩大。
- 未定参数只阻断依赖它们的计算。后续数据契约、可行性与案例准备可独立规划，但本 PR 不启动 A-05 或应用开发。
