## 七项工程建议

| 条目 | 建议 | 证据边界 |
|---|---|---|
| ENG-01 系统与架构 | 最低部署 macOS 15.0，arm64 优先 | Intel 留待 Phase 0 构建实验，不提前承诺或取消；交叉编译不等于真机支持 |
| ENG-02 性能基准 | M1 / 16 GB / 内置 SSD / Release | 是验收基准，不是已验证最低配置；冷/热缓存和内存峰值分开记录 |
| ENG-03 工具链 | 候选 Xcode 26.6、Swift 6 严格并发、GRDB v7.11.1 | 精确固定工具链及依赖；尚未集成或构建，不以 beta 作为发行基线 |
| ENG-04 模块 | 原生 SwiftUI App、本地 Swift Packages、AppEnvironment 注入 | 核心计算不依赖 UI/数据库/网络，Provider DTO 不直接进入 UI |
| ENG-05 存储 | SQLite/GRDB 唯一业务库，偏好用 UserDefaults，Key 用 Keychain | 不引入 SwiftData；Phase 0 只做空 schema、迁移框架和恢复契约 |
| ENG-06 测试 | Swift Testing 用于纯计算/契约，XCTest 用于 UI/系统/性能 | 固定预期独立保存；参考核算不等于生产实现或完整验收 |
| ENG-07 CI/发布 | 私人材料留本地，未来代码从干净历史逐文件发布 | 代码公开和公开 CI 另需授权；CI 退出项须真实证据，不自动完成 |

## 实施与验证边界

最低 macOS 的真实运行、Intel 支持、正式工具链和基准硬件均仍待证。
不因高版本编译成功推断低版本运行成功，不把当前机器当作已验证性能基准。
金额持久化遵守已选 Decimal 精度，不通过 SQLite REAL 偷换；需往返测试。
迁移失败不得自动清库；恢复须冲突重映射、引用检查和原子提交/回滚。
备份一致性须覆盖 SQLite 活跃日志；Keychain 属性读回、日志脱敏须真实验证。
Phase 0 存储与恢复按已确认 ORD-04/08 随实体扩展，不提前完成后期功能。
未来 UI/设置页工作须先使用适用 UI/产品设计技能；本轮无页面或交互设计。

本地完成七项文档结构、任务 ID 及冻结来源一致性检查，未执行应用构建或运行测试。
公开摘要未含本地检查材料，不能从本 PR 独立复跑。
57 项核心参考核算不替代生产单测，84 个原验收情境仍未执行。
剩余算法/覆盖、提醒 48/64、恢复及性能证据不因本次审查而关闭。
