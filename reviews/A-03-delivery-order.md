## 数据与条件发布边界

DATA-000 在 Phase 0 启动，Phase 5 退出前由负责人基于至少三家供应商证据选择 A/B/C。十年历史、2018-02/2020-03/2022 压力期、NBBO、退市/OCC 覆盖、许可和成本核查仍需落实；本次未选择路线、供应商或采购方案。

Phase 2 的账本 EOD 数据与历史回测数据分别验证。期权日估值按既有 Mid 优先、无 Mid 时 Last 并标记 STALE 的规则处理；两者均无则明确不可估值，不跨缺口输出完整净值/收益。此降级不允许 Last 用于历史模拟成交，早期账本样本也不能冒充满足回测数据门槛。

| 路线 | 历史能力与发布条件 |
|---|---|
| 未选 | 可完成早期独立工作，不能把 Phase 5 标为已退出 |
| A | 完整历史研究、统计与适用概率校准经验证，并与卡片/风险复盘整合后，才进入对应发布验收 |
| B | 仅样本内历史统计/频率，不开放校准、Brier Score 或 Reliability Diagram；展示范围仍须明确，不能默认完整回测页。适用结果与整合经验证后才能发布 |
| C | Phase 6 延期；不开放 Bootstrap 真实世界概率。核心风险中性分析可继续，扫描器明确历史结果不可用且不承诺上线日期 |

A/B 数据可用也不自动开放 Bootstrap：参数、样本和可复现契约须另行确认及验收。历史窗口不足按各自规则隐藏或降级，不承诺积累完成日期。
