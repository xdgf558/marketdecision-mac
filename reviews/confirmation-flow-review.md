# 凭据确认流程与跨窗口失效审查

基于已合并 PR #18。保留条件 focusable、明确 ⌘R 替换与 ⌘D 删除。
本次调整设置交互和共享状态模型，不改变 Keychain 实现、权限或 LICENSE。

## 行为

- 取消按钮独立请求输入焦点；不再从确认框关闭的 onChange 请求焦点。
- 确认消费后不请求焦点，只有成功完成回调才请求；关闭/重开页面拒绝旧回调。
- 每个设置页拥有不含凭据内容的确认/焦点状态，共享模型维护进程内版本。
- 接受检查、保存或删除时即改变版本，使其他页旧确认失效并显示重新确认提示。
- 保存/删除调用在进入存储前校验预期版本和 busy，拒绝排队期间过期的操作。
- 即使仍显示“已保存”，另一页替换后也会使旧删除确认失效。
- 保存按钮帮助文字按保存/替换状态区分。

版本只协调共享同一模型的页面，不是跨进程或外部 Keychain 修改的事务锁。
检查状态也会保守地使旧确认失效。关闭页面不会撤销已发起的存储写入；
它只阻止旧完成回调请求焦点。未声称全部并发时序已覆盖。

检查后旧确认拒绝。使用 continuation 控制时序，不靠任意 sleep。
