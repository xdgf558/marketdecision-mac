# 凭据操作完成与确认交互审查

基于已合并 PR #17，保留三处按启用态决定 focusable 的修复。
本次不改 Keychain 存储实现、权限、供应商连接或 LICENSE。

## 变更

- 保存/替换成功、删除成功后，在存储操作结束后请求回到输入框。
- 只向发起操作且仍处于同一可见会话的设置页恢复焦点。
- 延迟焦点使用视图绑定的 task(id:)，视图消失自动取消；失活清理请求。
- 替换要求点击明确按钮或按 ⌘R；提示文字写明快捷键，Esc 取消。
- 首次保存菜单不带省略号，已保存时显示“替换凭据…”。
- 保持单份 Commands 和 focusedSceneValue，不给两个 scene 重复添加菜单。
