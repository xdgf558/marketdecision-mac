# Phase 1 stock quote and daily-bar candidate

This slice adds a candidate Alpaca IEX adapter, exact numeric decoding, bounded retry scheduling and accepted-payload SQLite persistence. The application still runs the synthetic DEMO. No live Alpaca request, account authorization, supplier qualification, UI change, Keychain change or production-network permission is included.

The adapter pins `feed=iex`, USD, `adjustment=raw`, daily aggregation and `asof=-` (no automatic symbol-history remapping). IEX is single-exchange coverage, not consolidated NBBO. Daily bars must precede the current New York calendar date, with explicit millisecond request boundaries and a window of at most 366 days. They are historical aggregates, not official settlement prices, adjusted return series or historical-fill evidence. Intraday/options/streaming are outside this slice.

`EquityDataClient` binds the exact request, capability configuration and entitlement before accepting source bytes. Persistence accepts only that wrapper. Quotes carry the original source timestamp; timestamp comparisons use explicit half-even milliseconds. Invalid/zero/crossed quotes retain explicit invalid flags; age is evaluated when consumed. The adapter grants no analysis usage. Source availability remains unknown and content versions are local hashes: historical retrieval is not vintage PIT and AS_OF dispatch is refused.

The JSON reader retains financial number tokens without a binary floating-point intermediate; unsupported precision, malformed JSON and duplicate keys fail. Numeric values are stored as decimal strings, alongside the original response bytes. Quote/null, bars/empty, partial pages, throttling and malformed responses remain distinct. A final page does not establish calendar completeness.

One adapter instance shares a monotonic dispatch scheduler, including copied values. GETs have at least 350ms spacing, at most three attempts, a 30-second scheduling/retry budget and a 10-second transport timeout. HTTP 429 and selected transient 5xx responses may retry; server Retry-After/reset constraints are never shortened to fit the budget. Authentication/entitlement errors do not retry or fall back to another feed. Transport failures map to a closed error without logging response bodies or credentials. Cancellation during backoff or after an uncooperative transport response prevents publication.

Migration `business.p1.v4` adds immutable equity records and page metadata. Raw bytes, new records and the page are committed in one SQLite transaction with an in-transaction revision check. Identical request-scope/content retrieval is a no-op; changed bars coexist as explicit local versions. Reads verify hashes/source linkage, and page reads validate record references. Source-cache cleanup preserves these raw documents while referenced. Existing research snapshot tables are unchanged. Automatic equity retention and large-history/crash performance are not qualified here.

Validation uses the public fixed test catalog and synthetic payloads. The new tests cover exact prices, feed/query binding, missing rights, AS_OF rejection, stale/invalid quotes, malformed and partial pages, server backoff, cancellation, source substitution, New York DST, SQLite restart, idempotency, revisions, rollback/retry, migration, reference integrity and corruption refusal. The optional real Keychain test remains NOT EXECUTED. The clean local candidate passed 186 executed Swift tests out of 187 declarations, with one real Keychain test NOT EXECUTED; 24 tests are new in this slice. Xcode 27 beta 6 also passed 12 traceability checks, 4 UTC checks, Debug/Release ad-hoc builds, effective demo permissions and Release isolation. Hosted CI and native UI were not rerun for this candidate yet. Source tests are not live-provider acceptance.

The API shape was checked against official Alpaca documentation: [latest quote](https://docs.alpaca.markets/us/reference/stocklatestquotesingle-1), [historical bars](https://docs.alpaca.markets/us/reference/stockbarsingle-1), and [plans/authentication](https://docs.alpaca.markets/us/docs/about-market-data-api). The Basic tier's IEX coverage informed the candidate choice; it does not establish this user's account rights or redistribution permission.

Before live use, transport redirect/cookie/cache behavior, real account/license evidence, credential sourcing and any production entitlement change require review. No URLSession + adapter composition is added here. This candidate does not close Phase 1/G1, DATA-000/G5, financial-model acceptance or later option-chain work. Private specifications, task/memory records, real credentials and validation artifacts remain local.
