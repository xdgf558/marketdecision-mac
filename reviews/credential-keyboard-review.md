# 凭据菜单与键盘操作审查

本次基于已合并 PR #16，仅调整原生设置页的菜单与键盘交互。
合并本 PR 不等于 Phase 0 / DATA-001 退出或完整无障碍验收。

## 变更

- 用正式“凭据”菜单替代隐藏的 ⌘L 按钮，通过当前 scene 提供命令。
- 聚焦、保存/替换、删除、检查命令随当前页面和存储状态启用。
- 凭据区按输入、保存/替换、删除、检查顺序移动焦点，跳过禁用按钮。
- Tab / Shift-Tab 在区内移动；边界交回系统键盘导航。
- 获得焦点的操作按钮接受空格或 Return；禁用后清理旧焦点。
- 删除仍需确认，⌘D 完成删除，Esc 取消；取消替换/删除后返回输入框。
- 不改 CredentialStorage 注入、Keychain 实现、权限、供应商连接或许可。
